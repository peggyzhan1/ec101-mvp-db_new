# 活动费用核验报告模版（待评审）

下载用的 Excel：[`docs/templates/活动费用核验报告模版.xlsx`](templates/活动费用核验报告模版.xlsx)。  
用 `python3 scripts/build_activity_verification_template.py` 重生成。样例行来自兴路强「可口可乐满减」，核算日 `2026-09-22`。

请在「字段说明」表最后一列写保留 / 删除 / 改名。定稿前不开发下载。

## 报告怎么切

一份报告 = **一个活动 × 一次核算**。不是整批导入、也不是全店所有订单。

| 工作表 | 一行是什么 | 要不要 |
|---|---|---|
| 活动核验结论 | 整份报告的封面汇总 | 要 |
| 参与订单明细 | 参加了这个活动的一张订单 | **主表，请先评这些字段** |
| 订单商品行（附录） | 上面某张订单的一个商品行 | 建议保留作抽查，默认不拿来加总费用 |
| 字段说明 | 给评审用 | 开发时不会导出给业务 |

没有活动核销的订单不会出现。

## 参与订单明细：建议字段

计费只认 **活动优惠金额**。橙色三列现在空着，等标准活动配置进表并改核算后再填。

| 字段 | 现在能否填 | 作用 |
|---|---|---|
| 序号 | 能 | 行号 |
| 经销商名称 / 平台名称 | 能 | 这份报告属于谁 |
| 活动编号 / 活动名称 / 活动类型 | 能 | 哪个活动 |
| 核算日 / 释放截止时刻 | 能 | 这次怎么判 T-2 |
| 单据编号 | 能 | 订单主键 |
| 下单时间 | 能 | 是否早于截止时刻 |
| 客户编号 / 客户名称 / 所属业务员 | 能 | 对账找人 |
| 订单状态 | 能 | 是否「已完成」 |
| 订单来源 / 订单类型 / 支付方式 | 能 | 备查，不参与释放 |
| 活动商品金额 | 能 | 该单在本活动核销里的商品金额 |
| **活动优惠金额** | 能 | **本活动费用** |
| 是否可释放 / 释放结论 | 能 | 是 / 否，以及原因 |
| 同单券优惠金额 | 能 | 该单若还有券，只备查，不计入本活动 |
| 理论权益 / 一致性 / 差异金额 | 现在空 | 以后按旧 MVP 核算再填 |

没有放进去、需要你决定的：

- **订单行优惠合计**：平台所有促销加总，容易和活动优惠搞混，默认不放主表。
- **应赠 / 实赠件数**：满赠以后再加列，现在满赠主表金额为 0，只看单数。
- **商品行**：放到附录。一行订单可能有几十个商品（样例单 38 行）；行上的优惠是分摊，**不能加总替代核销 15 元**。

## 封面汇总（现在能出的数）

样例：可口可乐满减，参与 136，可释放 133，待释放 3，核销 2040，可释放金额 1995，待释放 45。理论权益、一致订单数留空。

## 请你拍板的三件事

1. 主表这 25 列，要留下哪些、删哪些、改什么名字。
2. 附录「订单商品行」要不要随报告一起下载。
3. 优惠券是另出一份「按券」的核验报告，还是只保留主表里的「同单券优惠金额」。
