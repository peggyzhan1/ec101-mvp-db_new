# ROI 分析口径（已确认）

每个活动或每张券各算一行。费用仍只认核销，不用规则替换 1995 / 200。

## 公式

```
订单 = 核销参与单
     AND 订单状态 = 已完成
     AND 下单时间 ∈ 上线期间

可乐行 = 上述订单的 order_line
       JOIN product（同一导入批次、同一商品编号）
       WHERE product.brand = '可口可乐'

可乐订单数 = COUNT(DISTINCT 含可乐行的订单)
可乐销量   = Σ 行数量换算成瓶/罐
可乐实付   = Σ order_line.paid_amount
费用       = Σ 核销优惠金额（同一批已完成参与单）

ROI = 可乐实付 / 费用     （满赠不算，费用为 0 也不算）
```

换算：单位是瓶或罐 → 用行数量；单位是箱或件 → 行数量 × 箱规（没有箱规不捏造）。

## 上线期间

| 对象 | 期间 |
|---|---|
| 活动 | `activity.start_time` ~ `activity.end_time` |
| 优惠券 | `coupon_use_rule.use_start_at` ~ `use_end_at` |

开始或结束为空：该行标「期间缺失」，不出销量/金额/ROI。
